## A mood tracking web application that reads journal entries or uploaded files and detects emotional tone through sentiment analysis. (In Progress)

## User Flow: 
- Write an Entry
- Scan
- See what emotion defines your writing

## How it works: 
- Using the `j-hartmann/emotion-english-distilroberta-base` transformer to classify text across seven emotions: fear, anger, surprise, disgust, joy, sadness, neutral

## Tech Stack: 
- HTML
- CSS
- Javascript
- Colab
- Python/HuggingFace
